🎓 STUDENT MANAGEMENT SYSTEM

Experiment 12 | React JS

📌 About the Project

A simple and interactive Student Management System developed using React.js. This application includes Registration, Login, Contact, and About pages, with smooth navigation using React Router DOM.

🎯 Objective

To develop a multi-page React application and understand component creation, form handling, and client-side routing.

🛠️ Tech Stack

⚛️ Frontend: React.js
💻 Language: JavaScript
🌐 Structure: HTML and CSS
🔀 Routing: React Router DOM
📦 Package Manager: npm
✨ Key Features

📝 Student Registration page
🔐 Login page
📞 Contact page
ℹ️ About page
🔄 Seamless navigation between pages
⚙️ Form handling using React Hooks
🚀 Getting Started

Step 1: Install dependencies

npm install

Step 2: Install React Router DOM

npm install react-router-dom

Step 3: Start the application

npm start

Open the local URL displayed in the terminal to view the application.
